# Приложение "Физиогномика" (Clean Architecture)

Это приложение для структурированного анализа черт лица на основе классической физиогномики.
Проект построен на принципах **Чистой Архитектуры (Clean Architecture)** с использованием Jetpack Compose.

## 🏗 Архитектурные принципы
1. **Строгое разделение слоев:** `domain` (модели) -> `data` (хранение) -> `presentation` (UI).
2. **Изоляция фич:** Каждый экран (или группа экранов) живет в своей папке.
3. **Никаких лишних библиотек:** Только стандартные средства Android (Compose, SharedPreferences, Navigation) и `kotlinx.serialization` для JSON.

## 📂 Структура проекта

```text
com.kirill.physiognomy
│
├── data/                          # Слой Данных (сохранение в SharedPreferences)
│   └── repository/
│       ├── ProfileRepository.kt   # Интерфейс
│       └── ProfileRepositoryImpl.kt # Реализация
│
├── domain/                        # Ядро (чистый Kotlin, не зависит от Android)
│   └── model/
│       ├── AppConstants.kt        # Константы (макс. фото и т.д.)
│       ├── PhotoItem.kt           # Модель фото (путь, эффекты)
│       └── ResearchProfile.kt     # Модель профиля (имя, возраст, ответы)
│
└── presentation/                  # UI Слой
    ├── MainActivity.kt            # Главный диспетчер экранов (навигация)
    │
    ├── theme/                     # Цвета, шрифты, тема
    │
    ├── onboarding/                # Экран 1: Приветствие
    │   └── OnboardingScreen.kt
    │
    ├── profile/                   # Экран 2: Создание профиля
    │   ├── ProfileSetupScreen.kt
    │   └── ProfileViewModel.kt
    │
    └── workspace/                 # Экран 3: Рабочее пространство
        ├── WorkspaceScreen.kt     # Экран подтверждения создания профиля
        │
        ├── editor/                # Компонент: Фото-редактор
        │   ├── PhotoEditor.kt
        │   └── PhotoEditorViewModel.kt
        │
        ├── blitz/                 # Фича: Блиц-чеклист (7 шагов)
        │   └── BlitzChecklistScreen.kt
        │
        └── deep/                  # Фича: Углубленный чеклист (26 шагов)
            └── DeepChecklistScreen.kt

📱 Поток экранов (User Flow)
Onboarding (Приветствие): Объясняет суть приложения. Кнопка "Начать".

Profile (Профиль): Ввод Имени, Возраста, Пола и выбор режима (Блиц/Углубленный). Сохраняет данные.

Workspace (Успех): Показывает, что профиль создан. Кнопка "Перейти к анализу".

Checklist (Анализ): Главный экран (в зависимости от режима). Верхняя часть — фото-редактор. Нижняя — вопросы.

🧠 Что нужно знать перед работой
Навигация: Управляется вручную через when(currentScreen) в MainActivity.kt. Это простая и надежная схема на текущем этапе.

ViewModel: Используются для управления состоянием. В UI-компоненты передаются только нужные данные через StateFlow.

Фото: Хранятся в виде URI (строки). Настройки (яркость, Ч/Б) применяются на лету в PhotoEditor.kt.

🛠 Список файлов, которые понадобятся из чата (источники)
Если вы продолжите разработку в новой сессии, вам (или агенту) понадобятся эти данные:
